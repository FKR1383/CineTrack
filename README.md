# CineTrack

CineTrack is a Flutter application for discovering movies and TV shows, managing personal lists, and tracking watched content.

## Project variants

- [`advanced/`](advanced/) - the full client-server version, with a Flutter mobile app and Python backend.
- [`simple/`](simple/) - a standalone Flutter version that stores its data locally.

Each variant includes its own setup and usage instructions in its README.

## SHA-256 manifests

The `MANIFEST.sha256` file in each variant records SHA-256 checksums for project files. These hashes can be used to verify file integrity: a matching checksum means the file has not changed, while a mismatch means it was modified or corrupted.
